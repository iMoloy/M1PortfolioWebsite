## 📖 Overview

**M1PortfolioWebsite** is the first iteration of Moloy Krishna Paul's personal portfolio website — a clean, responsive single-page portfolio built with HTML, CSS, and Google Fonts (Open Sans). It highlights skills, projects, and contact information.

> **Live at** → [https://imoloy.github.io/M1PortfolioWebsite](https://imoloy.github.io/M1PortfolioWebsite)

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| **HTML5** | Semantic page structure |
| **CSS3** | Custom layout and styling |
| **Google Fonts (Open Sans)** | Clean, readable typography |
| **Font Awesome** | Icons |

---

## ✨ Core Features

- **Hero Section** — Personal introduction with name and role
- **Skills Section** — Visual display of technical competencies
- **Projects Section** — Links to live projects and repositories
- **Contact Section** — Email and social media links
- **Responsive Design** — Adapts to mobile and desktop

---

## 📦 Dependencies

No npm packages. CDN resources only:

| Resource | Source |
|---|---|
| Google Fonts (Open Sans) | `fonts.googleapis.com` |
| Font Awesome | CDN |

---

## 🚀 Run Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/iMoloy/M1PortfolioWebsite.git
   cd M1PortfolioWebsite
   ```

2. **Open in browser**

   ```bash
   open index.html
   ```
